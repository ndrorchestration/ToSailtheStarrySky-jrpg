# Aureate Wake editable shared-hull review

Source review stacked on #846 `e8948deb01370a7bb5b2dadf38a0b1d8fe4694d7`.
Noncanonical Seabourne art assembly, isolated from player ship authority.

The generator reuses the project's original V2 ivory/brass hull and forward
geodesic bridge candidate, and the corrected #626 root-pivoted dragonfly wing.
It adds a cylindrical connected dorsal mount and a curved hydrofoil/strut
assembly. One wing mesh is instanced exactly four times. Four `SailAzimuth`
parent nodes give independent yaw while each child retains its 98-degree
upright/aft-raked deployment. Exactly two foil assemblies attach to the hull.
The forward dome stays fixed. The assembly GLB preserves the named hierarchy.

All dimensions are provisional design datums. The original 8 m review hull
and small bridge remain unresolved human-scale studies, not habitable final
assets. Four mast roots now sit **behind** the forward dome at X 105, -25,
-155, -285 cm, Y 0, Z 113 cm; feet overlap the upper hull/spine at Z 31 cm. This avoids perpetuating
the earlier proxy mast placed on the bridge roof. Actual surface contact,
structural load paths, crew access and continuous moving clearance remain
review gates. +/-35-degree trim is a provisional input bound, not certification.

## Reproduce

```sh
python unreal/ArtSource/ShipReview/build_aureate_shared_hull_rig.py --output-dir <EMPTY_DIR>
python -m unittest discover -s unreal/Tests -p test_aureate_shared_hull_rig.py -v
```

Native UE 5.8.4 Editor Python: set `TSTSS_SHIP_EXPECTED_HEAD` to the clean
review commit, then execute `unreal/Tools/stage_aureate_shared_hull_rig.py`.
It refuses occupied outputs, imports five separate mesh types, checks actual
centimetre/up-axis bounds, constructs twelve attached mesh actors, tests all
eight independent +/-35-degree yaw endpoints, saves and reloads a **new** map,
and captures three native views. No old map or asset is overwritten.

Map: `/Game/TSTSS/Review/SharedHullRigV2/L_AureateWake_Seabourne_EditableReview`.
In the World Outliner select `SailAzimuth_1` through `_4` and adjust yaw in
Details. Child wing, ferrule and mast turn together without rescaling geometry.
`AureateWake_SHARED_HULL_REVIEW` moves the whole assembly. This is an Editor
art rig, with collision disabled; it is not playable sailing or a physics rig.
It does not bind First Wake state, alter SaveGame or unlock any configuration.

Generated GLBs, manifest, native receipt and PNGs are under ignored
`unreal/Saved/SharedHullRigV2`; generated assets/map are ignored under the
distinct `Content/TSTSS/Review/SharedHullRigV2` folder. Source code is the
reproducible deliverable. Source and asset SHA receipts are separate because
different Python/libm/zlib platforms can produce different generated bytes.
